## About

A minimal, highly customizable startpage.

## Features

### Full visual customization

Everything you see can be customized.

  * **A studio for every widget.** Clock, search bar, and Quick Links each have their own editor with sliders for size, spacing, padding, corner roundness, opacity, blur, colors, glow, and shadow. so on.
  * **Visual editor** to drag, drop, and place widgets anywhere on the screen
  * **Background** as an image URL, an uploaded image, or an uploaded video, with built-in blur, dark, and position controls.

### Workflow

Everything you need for a fast workflow.

  * **Custom Site Shortcuts:** type `@key` in the search bar to search a specific site (e.g. `@gpt hello`, `@yt roblox`)
  * **Engine Switching:** switch between 4 default search engines or set a custom search provider.
  * **Quick Links:** Organize your favourite sites with custom layouts.
  * **Transfer Settings:** Export and import your complete layout and settings instantly with a single JSON file.

### Privacy and Performance

Built to be fast, lightweight, and private.

  * **Local-first.** Everything stays in your browser's `localStorage`.
  * **Lightweight.** No heavy dependencies, no analytics, no external databases, no tracking.

## Usage

To use this as your new tab page, install one of the extensions below and point it to the live URL.

**Live URL:** [https://anoxle.github.io/startpage/](https://anoxle.github.io/startpage/)

### Extensions

- **Chrome / Brave / Edge / etc:** [New Tab Redirect](https://chromewebstore.google.com/detail/new-tab-redirect/icpgjfneehieebagbmdbhnlpiopdcmna)
- **Firefox / Zen / Waterfox / etc:** [New Tab Override](https://addons.mozilla.org/en-US/firefox/addon/new-tab-override/)

**Note:** The extensions above may not work on Opera, Opera GX, or Comet. You'll need a third-party extension or another solution for those.
